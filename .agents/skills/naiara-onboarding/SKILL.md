# Acompañamiento inicial

Leer INICIO-IA.md en la raíz del kit y el Estado actual local si existe. Comprobar dónde se ejecuta la sesión; no confundir Windows local con un entorno remoto. Preguntar sólo los datos que faltan, hasta tres juntos.

Elegir una etapa que avance el objetivo actual de Naiara. Explicar para qué, acción concreta y resultado esperado. Usar instrucciones de docs/01-windows.md para instalación y docs/03-conexiones.md cuando toque una conexión. No instalar todo por rutina.

Preferir una prueba local gratuita al empezar: leer una nota, guardar un brief y retomarlo en otra sesión. Si está bloqueado un script, explicar operaciones manuales sin desactivar políticas. Registrar avance sólo después de comprobarlo.

No pedir secretos por chat ni asumir suscripciones o presupuestos. Respetar cambios de objetivo; si Naiara ya completó una etapa, verificar lo necesario y continuar, sin rehacer onboarding completo.
